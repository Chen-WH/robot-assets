# Reorientation Cylinder

Assets for the nominal 60 mm diameter by 80 mm tall wooden cylinder used by the
DexHand contact-explicit fingertip-gait experiment.

- `mjcf/reorientation_cylinder.xml`: free-body MuJoCo cylinder with frame sensors;
- `apriltag/physical_cylinder_tag_layout.yaml`: planned top/bottom tag attachment;
- `apriltag/generate_cylinder_apriltags.py`: reproducible tag36h11 print assets.

Geometry, mass, friction, printed tag size, and tag-to-cylinder transforms are
simulation/design values until they are measured on the physical specimen.
